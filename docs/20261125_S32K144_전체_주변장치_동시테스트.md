# 전체 주변장치 동시 구동 테스트 — S32K144 (2026-11-25)

**파일:** `src/main_all_test.c` · **브랜치:** `jun_GPT`

## 목적

서보 모터와 초음파 센서가 각각 보드에 고정되어 있으므로, 그 두 장치를 하나의 회전형 센서라고 간주하지 않는다. 대신 **모든 주변장치를 같은 프로그램에서 동시에 검사**한다.

| 장치 | 동작 |
|---|---|
| Clock + LPIT | 실제 1ms Tick 생성 |
| Servo (FTM PWM) | 초기 각도 유지. 디버거에서 `g_all_servo_request_mdeg`를 바꿀 때만 이동 |
| Ultrasonic (GPIO Trigger + FTM Capture) | 고정 방향에서 약 100ms 간격으로 거리 측정 |
| ADC | 가변저항 연속 측정, `g_all_adc_raw` 갱신 |
| OLED (SSD1306) | 약 300ms마다 거리·ADC·Servo·Stepper 상태 표시 |
| LCD (HD44780 등) | 사용자 구현 LCD 초기화/출력 함수로 거리·ADC·Servo 표시 |
| LED | 500ms마다 토글 (상태 표시 전용) |
| 버튼 | 눌림 횟수 카운트 (`g_all_button_presses`) |
| Stepper | 초기에는 정지. 실제 축의 원점 확인 후 디버거 명령으로만 이동 |
| RadarScan/Tracker | 이 모드에서는 **실행 안 함**. 고정 초음파 센서에 서보 각도를 붙인 가짜 좌표를 만들지 않음 |

**이 모드는 독립 주변장치 동시 Bring-up 펌웨어이며, 물리적으로 잘못된 2D 레이더 시연이 아니다.**

## 1. 먼저 확정해야 하는 설정 (필수)

다음은 회로도/장치 스펙/배선 검사 없이는 채울 수 없다.

- MCU 핀: Servo PWM/FTM/ALT, Ultrasonic Trigger GPIO 및 Echo FTM Capture/ALT, Stepper IN1~IN4, ADC 채널, OLED SDA/SCL, LCD 핀, LED, 버튼
- 기능 클록: LPIT, Servo FTM, Echo FTM, ADC/LPI2C
- LPIT 채널: Tick, Stepper, Echo Trigger가 서로 달라야 함
- 실제 초음파 Echo 논리 전압: 5 V 출력 장치를 S32K144 핀에 직접 연결하지 말 것 (허용 전압 확인/변환)
- Stepper 모터 드라이버·외부 전원·공통 GND, Servo 전원 및 기계적 한계
- 텍스트 LCD 컨트롤러 및 인터페이스 (HD44780 병렬인지 I2C 백팩인지 확인)

핀 정리 표: [핀 배치 및 독립 센서 가이드](20261124_S32K144_핀배치_단계별_실행_독립센서_벤치.md).

## 2. 빌드 방법

S32DS에서는 `src/main_all_test.c`와 전체 `src` 및 `src/header`를 프로젝트에 반영한다.

전처리기 Symbols:

```text
MP_TERP_ALL_TEST_MAIN
MP_TERP_USE_BOARD_CONFIG_TEMPLATE
```

**이 두 심볼만으로는 실제 장치가 구동되지 않는다.** `MP_TERP_CONFIRM_PINMAP`가 없으면 프로그램은 안전하게 `g_all_error=3`으로 멈춘다.

실제 배선 검증 및 설정이 끝나면 다음을 추가한다.

```text
MP_TERP_CONFIRM_PINMAP
```

- **다른 메인 심볼** `MP_TERP_STAGE_MAIN`, `MP_TERP_USE_EXAMPLE_MAIN`은 제거해야 한다.
- `src/main.c`는 전체 점검 모드에서 자동 비활성화된다.
- 실제 `board_config.c`가 있다면 `MP_TERP_USE_BOARD_CONFIG_TEMPLATE`을 제거한다.
- `src/board_config_user_template.c`의 `MP_TERP_GetBoardConfig()`는 기본 `false`를 반환한다. 실제 핀 배치를 확인하고 필요한 모든 값을 채운 후 `true`로 바꾼다.
- 같은 파일의 `MP_TERP_AllTestLCDInit()`도 기본 `false`를 반환한다. LCD 전원/핀과 인터페이스를 확인하고 실제 초기화 성공 시 `true`를 반환하도록 구현한다.
- 자체 `board_config.c`를 쓰는 경우 `MP_TERP_GetBoardConfig()`와 `MP_TERP_AllTestLCDInit()`을 각각 **정확히 한 번** 정의한다.
- LCD 출력은 `s_cfg.lcd_write(s_cfg.user,row,text)`를 통해 전달된다. `LCDHD44780_WriteLine`과 사용자 객체를 연결할 수 있지만, 콜백의 `user` 인자가 실제 LCD 인스턴스를 가리키도록 설정해야 한다.
- 실제 FTM 채널쌍 NVIC IRQ가 `MP_TERP_AllTestEchoCaptureIrq()`를 호출해야 한다. 버튼 PORT IRQ는 `MP_TERP_AllTestButtonPortIrq()`로 전달한다. **함수 선언만으로 IRQ가 자동 등록되지는 않는다.**

`MP_TERP_CONFIRM_PINMAP`는 코드 내 안전 게이트일 뿐 실제 회로/전압의 안전을 보증하는 인증은 아니다.

## 3. 실행 및 디버깅

S32DS에서 Clean → Build → Flash / Debug한 뒤 Expressions 창에 다음을 등록한다.

| 변수 | 의미 |
|---|---|
| `g_all_state` | 0 boot / 1 ready / 2 running / `0xDEAD` 실패 |
| `g_all_error` | 0 정상, 이외 실패 또는 I/O 오류 |
| `g_all_tick_ms` | LPIT 1ms Tick |
| `g_all_echo_samples` | 완료된 초음파 측정 건수 |
| `g_all_echo_valid` | 유효 거리 건수 |
| `g_all_echo_timeout` | Echo 실패·타임아웃 건수 |
| `g_all_range_mm` | 최근 거리 mm (무효면 0) |
| `g_all_adc_raw` | ADC 변환 결과 |
| `g_all_button_presses` | 버튼 누름 횟수 |
| `g_all_oled_updates` | OLED 전송 성공 횟수 |
| `g_all_lcd_updates` | LCD 갱신 시도 횟수 |
| `g_all_heartbeat` | LED 토글 횟수 |
| `g_all_servo_request_mdeg` | 원하는 서보 각도(mdeg) |
| `g_all_servo_applied_mdeg` | 마지막으로 수락된 서보 명령 |
| `g_all_stepper_homed` | 스텝 모터 물리 원점 설정 여부 |
| `g_all_stepper_moving` | 스텝 모터 동작 여부 |

### 서보 수동 명령

기계적 간섭·펄스 범위를 확인한 후 `g_all_servo_request_mdeg=90000`처럼 목표 각도를 디버거에서 변경한다. **초기에는 자동 스캔하지 않는다.**

### Stepper 원점 및 수동 명령

이 장치에는 엔코더가 없으므로 모터의 실제 각도를 펌웨어가 자동으로 알지 못한다.

1. 모터 축을 **기구적으로 확인한 기준 위치**에 둔다.
2. `g_all_stepper_home_angle_mdeg`에 그 위치의 각도(mdeg)를 입력한다.
3. `g_all_stepper_home_confirm=0x484F4D45`를 디버거에서 입력한다.
4. `g_all_stepper_homed=1`을 확인한다.
5. 아주 작은 각도 차이로 `g_all_stepper_request_mdeg`를 변경한다.

**확인 전에는 Stepper를 움직이지 않는다.** 실제 출력축 각도는 오픈루프 추정으로 표시되므로 별도 측정해야 한다.

## 5. 컴파일·검증 등급

- 현재 저장소에 구현된 전체 동시 메인은 **실제 S32DS 신규 빌드 결과 미확인**.
- 실제 핀맵/특정 보드 자료가 없기 때문에 사용자 현장 설정 함수는 아직 완성되지 않음.
- 이전 PC 시뮬레이션 6/6 PASS는 레이더 C 알고리즘 검증이며 이 펌웨어의 실제 주변장치 검증이 아님.
- **표적 3개/5개 추적은 본 동시 테스트에서 실행되지 않는다.** 2D 레이더 기능은 센서의 각도 측정 구조를 해결한 다음 `BoardSystem`으로 검증해야 함.

## 6. 권장 첫 실행

1. 보드/실습 확장보드 회로도 확인, 초음파 Echo 전압 보호 확인.
2. 빈 설정에서 `g_all_error=3`으로 안전 중단되는지 확인.
3. 검증된 실제 자원 배치를 `MP_TERP_GetBoardConfig`에 반영하고 LCD 초기화를 연결.
4. `MP_TERP_CONFIRM_PINMAP`을 활성화.
5. 오실로스코프/로직 분석기로 PWM·Trigger/Echo를 먼저 확인하고 MCU 및 드라이버 전원 조건 점검.
6. 전부 구동된 다음 LCD/OLED·ADC·LED·버튼을 관찰하고, 서보/스텝 모터는 수동 각도 명령으로만 테스트.

실물 핀 번호를 아직 알 수 없으므로 어떤 장치를 어느 핀에 연결하라는 **추정 지시를 하지 않는다**.
