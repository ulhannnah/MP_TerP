## 1. A안 — 기존 CPU 비차단 OLED (무조건 먼저)

S32DS Preprocessor Symbols:
- `MP_TERP_OLED_EDMA_ENABLE`: 제거 또는 값 `0`
- `MP_TERP_IDLE_WFI_ENABLE`: 제거 또는 값 `0`

Clean → Build → Debug, OLED/LED만 우선 연결. Expressions 점검:

| Expressions | 기대치 |
|---|---|
| `g_stage_state` | 2 |
| `g_stage_error` | 0 |
| `g_stage_oled_transport_mode` | 0 (CPU 비차단 FIFO) |
| `g_stage_oled_errors` | 0 유지 |
| `g_stage_oled_pages_sent` | 화면 변경 때 증가 |
| `g_stage_oled_data_bytes` | 실제 변경 열 크기만큼 증가, 128 × 페이지 횟수가 아님 |
| `g_stage_update_cycles_max` | 양수, 최대 관측값 유지 |

80MHz 기준 `g_stage_update_cycles_max / 80`은 관측된 한 번의 `BoardSystem_Update()` 최대 경과시간 µs. 이 값은 디버그/ISR 선점 효과도 포함하며 CPU 사용률 자체는 아님.

## 2. B안 — eDMA 기능 시험

A안이 성공했을 때만 S32DS Symbols 설정:
- `MP_TERP_OLED_EDMA_ENABLE=1`
- `MP_TERP_IDLE_WFI_ENABLE=0` (**첫 DMA 시험 때 WFI 금지**)

Clean → Build → Debug. 확인 순서:

1. ARM 컴파일 성공 여부 및 링커 오류 기록.
2. `g_stage_state=2`, `g_stage_error=0`, `g_stage_oled_transport_mode=1` 확인.
3. 화면 정상 갱신, `g_stage_oled_errors=0`, `g_stage_oled_pages_sent` 증가 확인.
4. 화면 내용이 변하지 않을 때 불필요한 전송이 증가하지 않는지 확인.
5. 가능하면 Scope/Logic Analyzer로 LPI2C START/STOP과 STOP 완료를 확인.

eDMA 전용 자원: DMA TCD **CH0**, DMAMUX **CH0**, 요청 source **45(LPI2C0 TX)**, LPI2C MDER TDDE. 다른 DMA 클라이언트와 중복 사용하지 않을 것. DMA 완료(DONE)만으로 전송 성공 판정하지 않으며 STOP(SDF)도 확인한다.

**이상 시 복구:** 전원 차단 및 외부 부하 제거 → S32DS symbols에서 `MP_TERP_OLED_EDMA_ENABLE=0` → Clean/Build/Debug. OpenSDA는 인식되지만 타깃 연결 실패 시 P&E Connect-under-Reset 또는 이전의 간단한 테스트 코드로 복구를 시도하고, 자동 Mass Erase는 먼저 수행하지 않는다.

## 3. 모터·센서 회귀 (시간 있을 때)

기능 확인은 A안부터 수행, B안에서 재확인:
- SG90 자동 스캔(FTM2) 정상 / 초음파 Echo 유효 범위 / LCD 갱신
- Stepper: 전원 전 기계적 90° 정렬(소프트웨어 원점), 외부 가변저항 PTB0로 조준각 변경, AIM PTC8 버튼 누른 뒤 Stepper 이동
- 릴레이: 처음에는 **부하 분리, PTE0 전압만** 측정. Stepper 목표 도착 후 RELAY PTC9 버튼으로 약 200ms HIGH 펄스, 이후 LOW. 시간은 실제 Scope 측정 전까지 추정
- PTC4(SWD_CLK)/PTC5(JTAG_TDI)는 외부 GPIO로 사용하지 않음
- 센서가 Servo에 결합되지 않았다면 기본 1D 고정 초음파 모드로 테스트: 실제 2D 표적 ID 생성 주장은 금지

## 4. C안 — WFI 전력 실험 (시간 남을 때만)

S32DS Symbols에 **동시에** `MP_TERP_OLED_EDMA_ENABLE=1`, `MP_TERP_IDLE_WFI_ENABLE=1` 설정. LPIT CH2 1ms Tick으로 CPU가 깨어난다. eDMA 없이 WFI를 켜면 빌드 오류로 방지한다. 디버거에서 Sleep/Resume 및 모든 화면/모터 기능을 별도 확인해야 하며, 전력 절감은 측정 전까지 주장하지 않는다.
