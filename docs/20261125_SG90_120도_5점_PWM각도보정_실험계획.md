# 2026-11-25 SG90 120° 운용 범위 및 5점 PWM–각도 보정 실험

> 프로젝트: MP_TerP / S32K144EVB-Q100  
> 개발 브랜치: `jun_GPT`; 기존 주변장치 Bring-up 기준본은 `snapshot/20261125-peripheral-bringup`에 보존  
> 상태: **코드 구조와 초기 보정표 구현 / 실측 보정값 및 개선 효과는 미확인**

## 1. 목표

SG90은 PWM 제어가 가능하지만 명령 각도가 실제 출력축 각도와 정확하게 일치한다는 보장은 없다. 목표 스캔 구간은 **명령상 30~150°(120° 범위)**로 제한한다. 실제 위치 오차는 각도기 또는 영상으로 측정하고 그에 맞춰 5개 PWM 보정점만 수정한다.

- 기존 `Servo_SetAngle(servo, angle_mdeg)` 호출부를 유지하고 드라이버 내부에서 **인접 보정점 간 구간별 선형보간**을 적용한다.
- 보정표를 사용 중일 때 30° 미만·150° 초과 명령은 `SERVO_ERR_RANGE`로 거부한다(하드웨어 PWM 허용 범위와 운영 각도 범위 분리).
- PWM 최소/최대 안전값(현재 **1100~1900 µs**)은 함부로 확대하지 않는다.
- 측정 전 초기값은 **기존 20~160° / 1100~1900 µs 선형 매핑의 재현값**이므로 정확도가 개선됐다는 뜻이 아니다.
- SG90은 외부 각도 피드백이 없으므로 보정 후에도 **개방루프**로 동작한다.

## 2. 실험 설정

| 항목 | 값 |
|---|---|
| MCU 출력 | PTD10 / FTM2_CH0 |
| PWM 주기 | 20 ms (50 Hz) |
| FTM 입력 클록 | SOSC 분주 클록 8 MHz 구성, prescaler 4 |
| 시간 분해능 | 0.5 µs/FTM tick |
| 주변장치 시험 방식 | 같은 펌웨어에서 SW2는 Stepper, SW3는 Servo |
| Servo 운용 목표 범위 | 30 / 60 / 90 / 120 / 150° |
| SW3 시퀀스 | 초기 90° → 30° → 60° → 90° → 120° → 150° → 90° |
| 각 명령 정착 대기 | `TEST_SERVO_HOLD_MS=2000` (2초) |
| 시험 횟수 | MCU Reset당 1회 (기존 SW2 Stepper 시퀀스 유지) |
| 출력 관찰 | `g_all_servo_applied_mdeg`, `g_all_servo_pwm_us`, `g_all_servo_calibration_point_index`, `g_all_servo_jog_state` |

※ PWM 주기, 분주값, 듀티의 수치는 소스 설정으로 계산된 값이다. PTD10의 파형 실측값은 아직 없다.

## 3. 현재 기초 보정표 (실측 전)

**아래 펄스 폭은 실물 측정 결과가 아니라 기존 PWM 맵에서 계산한 초기값이다.** 30°와 150°에서도 기구 간섭이 없는지 부하 없이 확인해야 한다.

| Index | 명령 각도 | 초기 PWM HIGH | 예상 Duty | 예상 FTM CnV | 실측 각도 | 오차(실측−명령) |
|---:|---:|---:|---:|---:|---|---|
| 0 | 30° | 1157 µs | 5.785% | 2314 | ______° | ______° |
| 1 | 60° | 1329 µs | 6.645% | 2658 | ______° | ______° |
| 2 | 90° | 1500 µs | 7.500% | 3000 | ______° | ______° |
| 3 | 120° | 1671 µs | 8.355% | 3342 | ______° | ______° |
| 4 | 150° | 1843 µs | 9.215% | 3686 | ______° | ______° |

현재 설정 파일은 `src/board_config_user_template.c`다. 아래 5개 값의 **pulse_us만 수정**할 수 있게 했으며 각도 정의 및 내림차순/범위 오류를 검증한다.

```c
cfg->servo_calibration_count=5u;
cfg->servo_calibration[0]=(ServoCalibrationPoint){30000,1157u};
cfg->servo_calibration[1]=(ServoCalibrationPoint){60000,1329u};
cfg->servo_calibration[2]=(ServoCalibrationPoint){90000,1500u};
cfg->servo_calibration[3]=(ServoCalibrationPoint){120000,1671u};
cfg->servo_calibration[4]=(ServoCalibrationPoint){150000,1843u};
```

5점 입력은 **각도 및 펄스 폭이 모두 엄격한 오름차순**이어야 하고 각 점은 기존 안전 PWM 범위와 각도 범위 내부에 있어야 한다. 표가 잘못되면 활성화하지 않는다.

## 4. 보간 방법

두 기준점 `(angle_i, pulse_i)`, `(angle_{i+1}, pulse_{i+1})` 사이의 명령 각도 `angle`에 대해

```text
pulse_us(angle) = pulse_i
  + round((pulse_(i+1) - pulse_i)
          * (angle - angle_i)
          / (angle_(i+1) - angle_i))
```

정수 연산과 반올림으로 처리한다. 예를 들어 60°의 펄스가 1329 µs, 90°가 1500 µs라면 75° 명령은 약 **1415 µs**다.

**주의:** 모델은 특정 서보의 정밀한 센서 기반 보정 모델이 아니다. 5개 점의 *실제 각도 측정과 보정용 PWM 재결정* 이후에만 각도 정확도 향상을 평가할 수 있다.

## 5. 실제 측정 및 보정 순서

1. 서보 혼에 가벼운 표시 지침을 부착하고 기구적 저항 없이 고정한다. 주변 기구/초음파 센서는 분리한다. 안전한 전원, GND 공통 연결을 확인한다.
2. `jun_GPT`를 받아 S32DS에서 Clean → Build → Flash/Debug → Resume.
3. SW3 누름으로 보정 워크를 시작한다. 30°, 60°, 90°, 120°, 150°를 거쳐 90°로 돌아온다. 스텝 모터는 SW2로 별도 시험하고 동시에 구동하지 않는다.
4. 각 위치에서 **실제 각도**를 측정하고 표 3에 적는다. 권장: 각도기 사진 또는 고정 카메라 영상으로 사후 프레임별 위치 측정.
5. 각 지점을 두 방향에서 반복 측정해 히스테리시스/기어 유격을 평가한다. 각도 차가 크면 단일 테이블로 양방향 오차를 모두 제거할 수 없음을 기록한다.
6. 원하는 실제 각도를 만드는 PWM 값을 실험적으로 찾아 `src/board_config_user_template.c`의 5개 `pulse_us`만 교체한다. 1100~1900 µs 범위를 넘겨 안전 동작을 강요하지 않는다.
7. 재시험 후 MAE, 최대 절대 오차를 비교한다. 실측 결과 없이 "정확도 개선"이라고 보고하지 않는다.

**서보 동작 안전:** 전원 인가 시 초기 90°로 이동할 수 있다. 기계적 걸림, 떨림, 발열, 과전류가 있으면 바로 전원을 차단하고 각도/전원 조건을 확인한다.

## 6. S32DS Debug Expressions

| 변수 | 의미 |
|---|---|
| `g_all_servo_jog_state` | 1: 버튼 Release 대기, 2: Ready, 3~7: 측정점 0~4, 8: 90° 복귀, 9: Done, 10: Error |
| `g_all_servo_calibration_point_index` | 0~4: 30~150° 측정점, 5: 중심 복귀 |
| `g_all_servo_applied_mdeg` | 최근 **요청한** 명령 각도, 실제 물리각이 아님 |
| `g_all_servo_pwm_us` | 최근 **계산하여 명령한** PWM High 폭(µs), 실제 출력 파형 측정값 아님 |
| `g_all_runtime_failed_mask` | 실행 중 실패한 주변장치 비트 |
| `g_all_error` | 마지막 오류 번호, 서보 명령 실패 시 42 |
| `g_all_motor_test_busy` | 0: idle, 1: Stepper, 2: Servo |

서보 오차를 확인할 때 `g_all_servo_applied_mdeg`와 `g_all_servo_pwm_us`뿐 아니라 **실제 샤프트 위치의 외부 측정값**도 반드시 기록한다.

## 9. 후속 결정 사항

- 실제 30~150°가 **정확히 가능한 구간**인지 첫 측정에서 확인한다. 일부 위치가 기계적 한계라면 더 좁은 범위로 재설정한다.
- 5점 실측값 확보 후 PWM 보정표를 갱신한다.
- 캘리브레이션 범위와 최종 레이더 스캔 범위를 통일한다.
- **센서–서보 물리 결합**이 아직 확인되지 않았으므로, SG90 보정 성공만으로 실제 각도별 초음파 레이더가 구현된 것은 아니다.
