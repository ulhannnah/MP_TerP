## 1. 이번 단계의 목적과 결론

각 주변장치를 **하나의 빌드/펌웨어**에서 점검하고, 독립된 두 버튼으로 Servo와 Stepper를 각각 왕복 구동하는 시험을 마련했다.

- **현재 사용자의 실기기 관찰:** Stepper는 정상적으로 움직였고, SG90 Servo도 버튼 명령 후 움직였다가 복귀하는 **기본 위치 제어 동작을 확인**했다.
- **SG90의 남은 문제:** 동작은 하지만 **실제 회전각이 명령 각도와 얼마나 일치하는지 애매함**. 현재 관찰만으로 100°의 *실제* 이동이나 각도 정밀도를 PASS로 판정하지 않는다.
- **Stepper의 남은 문제:** 기본 구동은 확인됐지만 100° 확장 시험의 **실제 출력축 각도**는 별도 측정값이 없다.
- **검증 상태:** 주변장치 **기본 기능 bring-up 완료 수준**. 전체 통합 기능, 실측 각도 보정, 장시간 안정성 검증까지 완료됐다는 뜻은 아니다.

## 3. 독립 버튼 모터 시험

같은 펌웨어에서 두 모터 드라이버를 초기화한다. `g_all_motor_test_busy`를 이용해 모터 시험의 **동시 시작을 막고**, 각 시험은 **리셋당 1회**로 제한한다. 새 펌웨어 업로드 없이 SW2·SW3로 구동한다.

### 3.1 Stepper — SW2

1. 현재 샤프트 위치를 **상대 0°**로 지정한다. 센서/엔코더로 원점 복귀(homing)하는 것이 아니다.
2. 상대 **0° → +100°** 명령.
3. 도착 후 **500 ms 유지**.
4. **+100° → 0°** 복귀하고 코일을 해제한다.

| 파라미터 | 값 | 비고 |
|---|---:|---|
| `TEST_STEPPER_TARGET_MDEG` | `100000` | 100° 명령 |
| `steps_per_revolution` | 4096 | 모터 출력축 실측 보정 필요 |
| 구동 모드 | Half-step | |
| `period_us` | 5000 μs | 5 ms/step |
| 편도 명령 스텝 | 약 1,138 | 4096 × 100/360, 반올림 |
| 이론적 편도 구동 시간 | 약 5.69초 | 1,138 × 5 ms |
| `TEST_STEPPER_TIMEOUT_MS` | 12,000 ms | 각 이동 단계의 안전 타임아웃 |
| 설정 각도 제한 | −110° ~ +110° | `StepperControllerConfig` |

**관찰 결과:** 이전 실기기 테스트에서 정상 회전과 복귀가 확인됨. 그러나 **이번 100° 확장 명령의 실제 회전각 검증 수치는 기록되지 않음**.

### 3.2 SG90 Servo — SW3

초기 90°에서 버튼을 누르면 순서대로 **90° → 40° → 140° → 90°** 명령한다. 40°에서 140°까지 **명령 범위가 100°**이며, 각 전환 단계는 1.5초 간격이다.

| 파라미터 | 값 | 비고 |
|---|---:|---|
| PWM | 50 Hz | 20 ms 주기 |
| FTM | FTM2 CH0 | PTD10, ALT2 |
| PWM 펄스 폭 설정 | 1100~1900 μs | 소프트웨어 매핑 범위 |
| 허용 명령 각도 | 20~160° | |
| 90° 명령 | 약 1500 μs | Duty 7.50% |
| 40° 명령 | 약 1214 μs | Duty 약 6.07% |
| 140° 명령 | 약 1786 μs | Duty 약 8.93% |
| `TEST_SERVO_HOLD_MS` | 1500 ms | 단계 간 대기 |

**실물 관찰(2026-11-25):** SG90이 버튼에 반응하여 움직이고, 다시 원래 위치로 돌아왔다. 이후 큰 동작 범위 코드에서 **정상 작동하지만 각도는 조금 애매하다**는 피드백이 있었다. 따라서 **PWM 명령에 반응하는 기능과 복귀 동작은 확인**했으나, **40°/90°/140° 실제 위치와 오차, 실제 100° 변위는 미측정**이다. 서보 고장으로 단정할 만한 관찰은 없다.

이 표의 μs/Duty 값은 소스의 선형 변환식으로부터 계산한 **설정상 예상치**다. 실제 PTD10의 PWM 주기/High 폭을 오실로스코프로 측정한 결과는 아니다.

## 4. 주변장치별 확인 수준

| 장치/기능 | 현재 평가 | 확인 근거 및 제한 |
|---|---|---|
| MCU 클록 / LPIT 1ms | 기본 동작 확인 | 이전 실기기 디버거에서 tick 증가와 heartbeat 확인 |
| 내장 LED | 기본 동작 확인 | 주기적 점멸 실물 확인 |
| ADC 가변저항 | 기본 동작 확인 | ADC 값 변화 관찰 |
| SW 버튼 입력 | 기본 동작 확인 | 버튼으로 모터 시험 시작 |
| OLED | 기본 동작 확인 | 앞선 모듈 구동 시험에서 화면 출력 보고 |
| 16×2 LCD | 기본 동작 확인 | 앞선 모듈 구동 시험에서 표시 확인 |
| 초음파 센서 | 기본 동작 확인 | 앞선 모듈 구동 시험에서 거리 측정 확인 |
| Stepper | 기본 구동 확인 | 회전/복귀 동작 확인, 실제 100° 이동량 미측정 |
| SG90 Servo | 구동 및 복귀 확인 | 정상 반응, 실제 각도 오차 미확정 |
| 2D 레이더/표적 추적 통합 | 미구현/미검증 | 현재 `main_all_test`는 주변장치 bring-up 전용 |

> 이 표는 사용자 관찰과 기존 시험 이력을 정리한 것이다. 모든 장치의 최신 통합 빌드에서 `g_all_ready_mask=255`, 오류 마스크=0 등을 새로 수집했다는 의미는 아니다. 본 기록에서 보드 전체의 장시간 스트레스 시험이나 독립적인 PWM 실측은 수행하지 않았다.
