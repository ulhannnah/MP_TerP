
# 기능별 명세

## 1. 레이더 스캔

### 하드웨어

- 서보 모터
- 초음파 센서

### 기능

- 서보 모터 30°~150° 왕복 회전
- 각도별 초음파 거리 측정
- 각도, 거리, 타임스탬프 저장
- 스캔 각도 간격은 추후 결정(TBD)

### 보드 하드웨어

- FTM (PWM): 서보 모터 제어
- FTM (Input Capture): 초음파 Echo 측정
- GPIO: 초음파 Trigger 출력
- LPIT: 스캔 타이밍 관리

### 구현

- `ScanManager` 상태 머신 구현
- `IDLE → MOVE → SETTLE → TRIGGER → WAIT_ECHO → STORE → ADVANCE`
- `ScanConfig`: 스캔 범위, 간격, 정착 시간, Timeout 설정
- `RadarSample`: 각도, 거리, 타임스탬프, 측정 상태 저장
- `scan_manager_init()`: 초기화
- `scan_manager_start() / stop()`: 스캔 시작 및 정지
- `scan_manager_update()`: 비차단식 스캔 처리
- `scan_manager_get_sample()`: 측정 데이터 반환
- `scan_manager_get_completed_frame()`: 단방향 스캔 데이터 반환
- Echo Timeout 및 스캔 경계각 처리

## 5. 다중 표적 추적

### 하드웨어

- 초음파 센서
- 서보 모터

### 기능

- 최대 5개 표적 관리
- 표적별 고유 ID 유지
- 이동 표적의 위치 및 속도 추정
- 기존 표적과 신규 표적 구분
- 표적 추적 실패 시 LOST 상태 관리

- Cortex-M4F FPU
- Cortex-M4 DSP 명령어
- SRAM: 표적 테이블 저장

- `RadarTarget`: ID, 위치, 속도, 상태, 타임스탬프 저장

- `target_tracker_predict()`: 등속도 기반 위치 예측
- `target_tracker_associate()`: 관측값과 기존 표적 매칭
- `target_tracker_update()`: 표적 위치 및 속도 갱신
- `target_tracker_register()`: 신규 표적 등록
- `target_tracker_mark_lost()`: LOST 상태 처리
- `target_tracker_get()`: ID 기반 표적 정보 반환
- 거리 기반 최근접 이웃 매칭
- 표적별 마지막 관측 시각 및 유효성 관리

- 스캔 누락, Timeout, ID 변경 횟수 기록
- CSV 형태의 실험 결과 출력 지원

## 16. 시스템 오류 복구 및 안전 관리

### 하드웨어

- S32K144 MCU
- LED 또는 릴레이
- 모터 드라이버

### 기능

- 센서 Timeout 및 비정상 데이터 처리
- 표적 LOST 시 조준 상태 변경
- 모터 구동 이상 및 범위 초과 방지
- 시스템 비정상 상태 감시
- 비정상 상태에서 발사 시뮬레이션 차단

### 보드 하드웨어

- WDOG: 시스템 동작 감시
- GPIO: 모터 드라이버 활성화 제어
- NVIC: 오류 인터럽트
- LPIT: 상태 감시 주기 관리

### 구현

- `SystemSafety`: 시스템 오류 및 안전 상태 관리
- `safety_init()`: 초기화
- `safety_check_sensor()`: 센서 상태 검사
- `safety_check_target()`: 선택 표적 유효성 검사
- `safety_check_motor()`: 모터 상태 검사
- `safety_allow_fire()`: 발사 시뮬레이션 허용 여부 반환
- `safety_enter_fault()`: 오류 상태 전환
- `safety_clear_fault()`: 오류 복구
- Watchdog 갱신 및 오류 상태 기록
- 오류 발생 시 LED/릴레이 비활성화
