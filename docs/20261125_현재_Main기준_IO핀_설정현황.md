## 2. 타이머 및 클록

| 자원 | 설정 |
|---|---|
| LPIT0 CH0 | Stepper, 5ms 간격 |
| LPIT0 CH1 | Trigger 종료, 10us |
| LPIT0 CH2 | 1ms Tick |
| LPIT0 CH3 | 예비 |
| LPIT clock | PCS6 / SPLLDIV2 40MHz |
| FTM2 CH0 | Servo, PCS1 SOSCDIV2 8MHz, 20ms 주기 |
| FTM0 CH6 | Echo, PCS1 SOSCDIV2 8MHz |
| ADC0 | PCS1, SE12, Vref 설정 5000mV (실제 전압 확인) |
| LPI2C0 | 기존 OLED 기본 설정 PCS6 |

FTM0과 FTM2의 카운터는 분리되며 LPIT 채널도 중복되지 않는다. Echo IRQ는 FTM0_Ch6_Ch7_IRQHandler, 버튼은 PORTC_IRQHandler를 전체 테스트 훅에 연결한다. S32DS startup에 동일한 강한 핸들러가 있으면 중복 정의를 제거해야 한다.

## 3. 임시 구동 파라미터

- Servo SG90: 허용 명령 20~160도, 1100~1900us, 초기 90도(1500us). SW3 누름 → 40도 → 140도 → 90도 (명령상 100도 범위). 실제 각도/펄스 관계는 미보정.
- Ultrasonic: Trigger 10us, timeout 30ms, 유효 Echo 100~25000us. 고정 방향 거리만 측정.
- Stepper: half-step, 4096 steps/rev 가정, 제한 -110~+110도. SW2 누름 → 상대 0도에서 +100도 이동 → 500ms 후 0도 복귀. 편도 약 1138 half-step / 약 5.7초(5ms/step), 타임아웃 12초. 실제 감속비에 따른 출력축 이동각은 측정해야 한다. 시작점은 절대 원점이 아닌 임시 상대 기준.
- LCD: HD44780 4bit, RW LOW, LPIT tick 기반 보수적 지연. 화면 전송이 느릴 수 있음.
- LED: 500ms 점멸. 버튼은 눌림 이벤트 기록. 자동 표적 추적이나 발사 기능 없음.

## 4. S32DS 주변장치별 독립 테스트 (2026-11-25 갱신)

`src/header/project_config.h`가 전체 주변장치를 한 번에 빌드하도록 선택한다. 실제 연결을 검증하고 모터를 외부 기구와 분리한 후 구동한다. IO 핀 배정은 1절과 동일하다.

```c
#define TEST_LED          1
#define TEST_ADC          1
#define TEST_BUTTON       1
#define TEST_OLED         1
#define TEST_LCD          1
#define TEST_ULTRASONIC   1
#define TEST_SERVO        1
#define TEST_STEPPER      1
#define TEST_STEPPER_BUTTON_JOG 1
#define TEST_STEPPER_TARGET_MDEG 100000
#define TEST_STEPPER_TIMEOUT_MS  12000u
#define TEST_SERVO_LEFT_MDEG     40000
#define TEST_SERVO_RIGHT_MDEG    140000
#define TEST_SERVO_CENTER_MDEG   90000
#define TEST_SERVO_HOLD_MS       1500u
```

최신 src 및 header를 S32DS에 반영하고 Clean / Build / Debug / Resume 한다. 이전 g_all_pinmap_confirm 승인 대기와 state=3은 제거했다. 디버거에서 메모리를 수정할 필요가 없다. SW2/Stepper와 SW3/Servo는 각기 단발 1회 자동 왕복한다. 시험 사이 동시 작동은 방지한다. 이후 다시 실행하려면 MCU Reset이 필요하다. Servo를 켜면 초기 PWM이 출력될 수 있으므로 연결 전 전압과 기계적 간섭을 확인한다.

| Expression | 기본 설정 기대값 |
|---|---|
| g_all_state | 2 (running) |
| g_all_error | 0 |
| g_all_boot_stage | 9 |
| g_lpit_init_stage | 7 |
| g_all_enabled_mask | 255 (전체 8개 기능 활성) |
| g_all_ready_mask | 255 (모든 드라이버 초기화에 성공한 경우) |
| g_all_failed_mask | 0 |
| g_all_runtime_failed_mask | 0 |
| g_all_tick_ms | 증가 |
| g_all_heartbeat | 500ms마다 증가 |
| g_all_adc_raw | 가변저항에 따라 변화 |
| g_all_button_presses | 버튼 이벤트마다 증가 (디바운싱 미검증) |

마스크 비트: LED=1, ADC=2, BUTTON=4, OLED=8, LCD=16, ULTRASONIC=32, SERVO=64, STEPPER=128. ready는 드라이버 초기화 성공이며 실제 장치 동작을 보증하지 않는다. failed는 초기화 실패, runtime_failed는 실행 중 기록된 오류이다. 일반 초기화 반환 오류는 다른 장치 실행을 중단하지 않는다. CPU Fault, 시스템 타이머 실패, 블로킹 드라이버는 예외이다. g_all_error는 마지막 오류를 표시한다. LCD 초기화와 버튼/Echo NVIC 설정을 분리했다.

실기기 확인 이력 (이전 빌드, 677e629 계열): LPIT init stage=7, state=3, boot stage=7, error=0, tick=40822 및 42704, heartbeat=81 및 85, ADC raw=2691 및 2600, Fault 기록=0. 내장 LED 점멸 확인. 새 독립 테스트 코드의 ARM 빌드/실기기 검증은 아직 수행하지 않았다.


### 2026-11-25 큰 회전각 단독 시험

| 버튼 | 시험 순서 | 목표 이동량 | 주의 |
|---|---|---|---|
| SW2 (PTC12) | Stepper 상대 0° → +100° → 0° | 편도 100° 명령 | 4096 half-step/rev 가정; 실제 각도는 별도 측정 |
| SW3 (PTC13) | SG90 90° → 40° → 140° → 90° | 40°↔140° 구간 100° 명령 | PWM 20ms, 제어 펄스 약 1.21~1.79ms, 실제 각도 확인 필요 |

SW2: `g_all_stepper_jog_state`가 2(대기) → 3(이동) → 4(대기) → 5(복귀) → 6(완료). SW3: `g_all_servo_jog_state`가 2(대기) → 3(40°) → 4(140°) → 5(90°) → 6(완료). `g_all_motor_test_busy`가 0일 때만 시작할 수 있다. Stepper 타임아웃/실패는 state 7, Servo 명령 실패도 state 7이다. 현재 코드의 제한은 모터 명령 각도만 의미한다. 엔코더가 없으므로 물리적 100° 이동을 보증하지 않는다.

**시험 전:** 드라이버/전원 용량, 공통 GND, 샤프트 간섭, 고정된 외부 기구와의 연결 여부를 확인한다. 서보/스텝 모두 부하 없이 시험하고, 걸림·이상음·발열이 발생하면 즉시 모터 전원을 끊는다. 최초 SG90 위치가 잘못 설정되면 전원 인가 직후 중심으로 회전할 수 있다.
