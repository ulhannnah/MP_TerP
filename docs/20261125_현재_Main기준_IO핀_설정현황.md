# 2026-11-25 S32K144 전체 테스트 Main — 임시 IO 핀맵 v1

기준: `src/main_all_test.c`, `src/board_config_user_template.c` / `jun_GPT`.

**상태: 코드에 임시 배정 반영, 실물 확장보드 배선 및 신규 빌드 미검증.** S32K144EVB-Q100 (Rev B Quick Start Guide 기준)에서 중복 없는 신호 배정이다. 실제 보드 리비전과 점퍼 연결을 대조한 뒤 사용한다.

## 1. IO 배치

| 기능 | MCU 핀 | EVB 헤더 | MUX / 기능 |
|---|---|---|---|
| Servo PWM | PTD10 | J1-06 | ALT2 / FTM2_CH0 |
| Ultrasonic TRIG | PTB8 | J1-05 | ALT1 GPIO |
| Ultrasonic ECHO | PTE8 | J2-08 | ALT2 / FTM0_CH6 |
| Stepper IN1 | PTB9 | J1-07 | ALT1 GPIO |
| Stepper IN2 | PTB10 | J1-09 | ALT1 GPIO |
| Stepper IN3 | PTB11 | J1-11 | ALT1 GPIO |
| Stepper IN4 | PTB5 | J2-05 | ALT1 GPIO |
| Potentiometer | PTC14 | J4-14 / 내장 | ADC0_SE12 |
| OLED SDA | PTA2 | J1-01 | ALT3 LPI2C0 |
| OLED SCL | PTA3 | J1-03 | ALT3 LPI2C0 |
| LCD RS | PTD4 | J4-01 | ALT1 GPIO |
| LCD E | PTD5 | J1-12 | ALT1 GPIO |
| LCD D4 | PTD11 | J1-08 | ALT1 GPIO |
| LCD D5 | PTD12 | J1-10 | ALT1 GPIO |
| LCD D6 | PTD13 | J2-01 | ALT1 GPIO |
| LCD D7 | PTD14 | J2-03 | ALT1 GPIO |
| LCD RW | GND | GND | 병렬 Write-only |
| LED | PTD15 | J2-02 / 내장 RED | ALT1, active-low |
| 버튼 | PTC12 | J2-10 / 내장 SW2 | ALT1, rising edge |

총 18개 MCU IO 신호에 동일 포트/핀 중복 없음. 기존 LIN PTD6/7, OpenSDA UART PTC6/7, CAN PTE4/5, SBC SPI PTB14~17, SWD/Reset 핀은 사용하지 않는다. OLED 주소 0x3C, HD44780 16x2 병렬 LCD를 가정한다. 실제 LCD가 I2C 타입이거나 확장보드에 고정 배선된 경우 해당 배치를 수정해야 한다.

## 2. 타이머 및 클록

| 자원 | 설정 |
|---|---|
| LPIT0 CH0 | Stepper, 5ms 간격 |
| LPIT0 CH1 | Trigger 종료, 10us |
| LPIT0 CH2 | 1ms Tick |
| LPIT0 CH3 | 예비 |
| LPIT clock | PCS6 / SPLLDIV2 40MHz |
| FTM2 CH0 | Servo, PCS1 SOSCDIV2 8MHz, 20ms 주기 |
| FTM0 CH6 | Echo, PCS1 SOSCDIV2 8MHz |
| ADC0 | PCS1, SE12, Vref 설정 5000mV (실제 전압 확인) |
| LPI2C0 | 기존 OLED 기본 설정 PCS6 |

FTM0과 FTM2의 카운터는 분리되며 LPIT 채널도 중복되지 않는다. Echo IRQ는 FTM0_Ch6_Ch7_IRQHandler, 버튼은 PORTC_IRQHandler를 전체 테스트 훅에 연결한다. S32DS startup에 동일한 강한 핸들러가 있으면 중복 정의를 제거해야 한다.

## 3. 임시 구동 파라미터

- Servo: 60~120도 명령 범위, 1300~1700us, 초기 90도(1500us). 실제 모터 각도/펄스 관계는 미보정.
- Ultrasonic: Trigger 10us, timeout 30ms, 유효 Echo 100~25000us. 고정 방향 거리만 측정.
- Stepper: half-step, 4096 steps/rev 가정, 명령 범위 -10~+10도. 실제 감속비와 모터 모델 확인 전 각도 정확도 미보장. 원점 확인 전 정지.
- LCD: HD44780 4bit, RW LOW, LPIT tick 기반 보수적 지연. 화면 전송이 느릴 수 있음.
- LED: 500ms 점멸. 버튼은 눌림 이벤트 기록. 자동 표적 추적이나 발사 기능 없음.

## 4. S32DS 주변장치별 독립 테스트 (2026-11-25 갱신)

`src/header/project_config.h`에서 아래 항목을 선택한다. 기본값은 내장 장치만 켜고 외부 배선이 확인된 장치만 1로 변경한다. 실제 IO 핀 배정은 1절과 동일하다.

```c
#define TEST_LED          1
#define TEST_ADC          1
#define TEST_BUTTON       1
#define TEST_OLED         0
#define TEST_LCD          0
#define TEST_ULTRASONIC   0
#define TEST_SERVO        0
#define TEST_STEPPER      0
```

최신 src 및 header를 S32DS에 반영하고 Clean / Build / Debug / Resume 한다. 이전 g_all_pinmap_confirm 승인 대기와 state=3은 제거했다. 디버거에서 메모리를 수정할 필요가 없다. 모터의 수동 각도 및 원점 명령은 기존 방식대로 유지한다. Servo를 켜면 초기 PWM이 출력될 수 있으므로 연결 전 전압과 기계적 간섭을 확인한다.

| Expression | 기본 설정 기대값 |
|---|---|
| g_all_state | 2 (running) |
| g_all_error | 0 |
| g_all_boot_stage | 9 |
| g_lpit_init_stage | 7 |
| g_all_enabled_mask | 7 (LED+ADC+BUTTON) |
| g_all_ready_mask | 7 |
| g_all_failed_mask | 0 |
| g_all_runtime_failed_mask | 0 |
| g_all_tick_ms | 증가 |
| g_all_heartbeat | 500ms마다 증가 |
| g_all_adc_raw | 가변저항에 따라 변화 |
| g_all_button_presses | 버튼 이벤트마다 증가 (디바운싱 미검증) |

마스크 비트: LED=1, ADC=2, BUTTON=4, OLED=8, LCD=16, ULTRASONIC=32, SERVO=64, STEPPER=128. ready는 드라이버 초기화 성공이며 실제 장치 동작을 보증하지 않는다. failed는 초기화 실패, runtime_failed는 실행 중 기록된 오류이다. 일반 초기화 반환 오류는 다른 장치 실행을 중단하지 않는다. CPU Fault, 시스템 타이머 실패, 블로킹 드라이버는 예외이다. g_all_error는 마지막 오류를 표시한다. LCD 초기화와 버튼/Echo NVIC 설정을 분리했다.

실기기 확인 이력 (이전 빌드, 677e629 계열): LPIT init stage=7, state=3, boot stage=7, error=0, tick=40822 및 42704, heartbeat=81 및 85, ADC raw=2691 및 2600, Fault 기록=0. 내장 LED 점멸 확인. 새 독립 테스트 코드의 ARM 빌드/실기기 검증은 아직 수행하지 않았다.
