# 마프설 텀프 아이디어

## 1. 자동차 R모드 구현 및 제어

### 	1. 사용 소자  

		**가변저항** - 가속페달 역할

		**dc 모터** - 바퀴 모형 역할

		**초음파 센서** - 장애물과의 거리 측정

		**Cds 센서** - 어두울 시 LED 점등하여 야간 상황 구현

		**부저** - 후진 경고음 역할

		**Segment** - 장애물과의 거리 표시

		**LCD** - 자동차의 상태 (P, R N D) 표시

		**스위치** - 자동차 기어 선택 역할

		(추가? 온 습도센서 - 공조장치, 스텝모터 - 자동차 속도계 			역할로?, 서보 모터 - 공조장치 구현한다면 공조 바람세기 조절 역할로)

### 	2. 시나리오

		1.  후진 준비 : 초음파 센서 앞에 장애물을 두고 후진 스위치를 누른다 -> 장애물 사이 거리가 충분하면 가변저항을 이용해 후진 (모터 구동) -> 일정 거리 이하로 들어오면 부저로 경고 울림 -> 정지 기준에 들어오면 dc모터 차단, LCD에 STOP표시

		2. 야간모드일 시 LED 점등함

		3. 확장) 온 습도에 따라 서보모터로 공조세기 조절 시연


## 2. 활주로 관제 시스템 : 유도로에서 활주로 진입 시 제어하는 시스템

### 	1. 사용 소자

		**초음파 센서** - 활주로 진입 전 유도로에 활주로로 통과 중인 차량이나 비행기 있는지 확인

		**스위치** - 활주로 상태 표시 (비어있음, 뭐가 있음)

		**키패드** - 관제탑 역할 (진입승인, 승인 취소)

		**LED** - RED, GREEN으로 정지, 유도 구현

		**Segment** - 남은 진입 가능 시간 구현

		**LCD** - 활주로 상태 표시 (Hold, Clear, Passing, Busy 등)

		**부저** - 승인 거부, 승인 취소 등을 알림

		**서보 모터** - 차단봉 구현

		확장? ) OLED로 항공뷰처럼 상황 시각화


### 	2. 시나리오

		1. 정상 상태 : 

		**스위치로 활주로 비어있는 상태 가정** / *LCD에 HOLD 표시, 	LED는 RED,*  서보모터 0도(차단봉) -> 

**키패드 1 (진입 승인) 누름**  -> 

초음파 거리 0, 비어있음 확인 시 *LCD는 CLEARD표시, LED GREEN, 서보모터 90도, segment 카운트다운 시작 ->* 

**진입**  , 초음파 센서 적당한 값 나오면 / *LCD에 PASSING ->* 

**통과 완료** / *거리 멀어지면 통과 완료, LED RED, 서보모터 0도*


		2. 오류 상태

		- 활주로에 뭐가 있는데 키패드 1(진입 승인) 누름 -> LCD에 BUSY 표시

		-  승인 직후 활주로에 뭐가 들어온 상황 -> 즉시 승인 취소, LED RED, 서보모터 0도, 다시 승인 요청 해야함

		- 승인과 활주로에 뭐가 동시에 들어온 상황(스위치)가 동시 발생 -> 스위치를 우선순위로 반영

		- Segment 시간 지나도 안 들어옴 -> LCD에 TIMEOUT, LED RED, 서보모터 0도로 되돌림
