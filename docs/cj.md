# 마프설 텀프 아이디어

## 1. 자동차 R모드 구현 및 제어

### 1. 사용 소자

		**가변저항** - 가속페달 역할

		**dc 모터** - 바퀴 모형 역할

		**초음파 센서** - 장애물과의 거리 측정

		**Cds 센서** - 어두울 시 LED 점등하여 야간 상황 구현

		**부저** - 후진 경고음 역할

		**Segment** - 장애물과의 거리 표시

		**LCD** - 자동차의 상태 (P, R N D) 표시

		**스위치** - 자동차 기어 선택 역할

		(추가? 온 습도센서 - 공조장치, 스텝모터 - 자동차 속도계역할로?, 서보 모터 - 공조장치 구현한다면 공조 바람세기 조절 역할로)

### 2. 시나리오

		1.  후진 준비 : 초음파 센서 앞에 장애물을 두고 후진 스위치를 누른다 -> 장애물 사이 거리가 충분하면 가변저항을 이용해 후진 (모터 구동) -> 일정 거리 이하로 들어오면 부저로 경고 울림 -> 정지 기준에 들어오면 dc모터 차단, LCD에 STOP표시

		2. 야간모드일 시 LED 점등함

		3. 확장) 온 습도에 따라 서보모터로 공조세기 조절 시연

## 2. 활주로 관제 시스템 : 유도로에서 활주로 진입 시 제어하는 시스템

### 1. 사용 소자

		**초음파 센서** - 활주로 진입 전 유도로에 활주로로 통과 중인 차량이나 비행기 있는지 확인

		**스위치** - 활주로 상태 표시 (비어있음, 뭐가 있음)

		**키패드** - 관제탑 역할 (진입승인, 승인 취소)

		**LED** - RED, GREEN으로 정지, 유도 구현

		**Segment** - 남은 진입 가능 시간 구현

		**LCD** - 활주로 상태 표시 (Hold, Clear, Passing, Busy 등)

		**부저** - 승인 거부, 승인 취소 등을 알림

		**서보 모터** - 차단봉 구현

		확장? ) OLED로 항공뷰처럼 상황 시각화

### 2. 시나리오

		1. 정상 상태 :

		**스위치로 활주로 비어있는 상태 가정** / *LCD에 HOLD 표시, 	LED는 RED,*  서보모터 0도(차단봉) ->

**키패드 1 (진입 승인) 누름**  ->

초음파 거리 0, 비어있음 확인 시 *LCD는 CLEARD표시, LED GREEN, 서보모터 90도, segment 카운트다운 시작 ->*

**진입**  , 초음파 센서 적당한 값 나오면 / *LCD에 PASSING ->*

**통과 완료** / *거리 멀어지면 통과 완료, LED RED, 서보모터 0도*

		2. 오류 상태

		- 활주로에 뭐가 있는데 키패드 1(진입 승인) 누름 -> LCD에 BUSY 표시하고 승인 절차 실행 X

		-  승인 직후 활주로에 뭐가 들어온 상황 -> 즉시 승인 취소, LED RED, 서보모터 0도, 다시 승인 요청 해야함

		- 승인과 활주로에 뭐가 동시에 들어온 상황(스위치)가 동시 발생 -> 스위치를 우선순위로 반영

		- Segment 시간 지나도 안 들어옴 -> LCD에 TIMEOUT, LED RED, 서보모터 0도로 되돌림

### 다른 레퍼런스들

#### 전기차 충전·주행 인터록 제어기

충전 케이블 연결과 차량의 주차 상태를 확인하고 모의 충전을 시작한다. 충전 중 출발 버튼을 누르면 모터가 멈춘 상태를 유지하고, 연결 해제 후 새 출발 요청을 받아 구동한다. 서보는 충전구 잠금, 릴레이는 충전 출력을 표현한다.

#### 상용차 보조전원·부하 우선순위 제어기

사용자가 조명, 송풍기, 편의장치를 요청하면 MCU가 가용 전력과 부하 우선순위를 비교한다. 가변저항으로 모의 전압을 낮추면 편의장치부터 끄고, 전력이 회복되면 순서대로 다시 켠다.

#### 공항 수하물 자동 분류기

키패드로 등록한 목적지를 대기열에 넣고, 초음파가 물체를 감지할 때마다 모터가 분류와 통과 동작을 표현한다. 물체가 센서 앞에 너무 오래 머물면 운반 모터를 멈추고, 처리 중인 수하물을 유지해 복구 후 재시도한다.

#### 큐브샛 전력관리 모의장치

CdS를 가리면 일조가 줄어 가상 배터리 잔량이 내려간다. MCU가 모의 발전량과 사용량을 시간에 따라 계산하고, 전력이 부족할 때 관측 장비 등 부하를 우선순위에 따라 끈다.

#### OLED 미니 오실로스코프

보드에서 만든 시험 신호를 일정 간격으로 읽고 OLED에 파형을 그린다. 시간축을 조절하거나 화면을 정지할 수 있고, MCU가 주기·주파수·듀티를 계산해 함께 보여준다.

#### LED–CdS 밝기 피드백 제어기

가변저항으로 목표 밝기를 설정하고 CdS로 측정한 밝기와의 오차에 따라 LED PWM을 조절한다. 주변광이 달라졌을 때 고정 PWM 운전과 피드백 제어가 목표 밝기를 얼마나 잘 유지하는지 비교한다.

#### LED–CdS 광통신 실험기

키패드로 고른 짧은 데이터를 LED 점멸 패턴으로 내보내고, CdS의 ADC 값으로 비트를 복원한다. 화면에 송신값과 수신값을 함께 띄워 조명이나 거리 조건에 따라 오류 발생 여부를 비교한다.

#### 물체 높이 분류기

초음파로 빈 구간의 기준 거리와 물체가 들어왔을 때 거리를 재서 높이를 계산한다. 높이에 따라 서보 분류기를 다른 위치로 움직이고, 스텝모터와 화면으로 이송과 분류 건수를 표시한다.

#### 생산라인 배치 카운터

작업자가 목표 수량을 입력하면 초음파가 물체 통과를 세고 FND에 진행 건수를 표시한다. 센서 앞에 물체가 계속 남을 때 중복으로 세지 않으며, 목표 수량이나 정체 조건에서 모터를 정지한다.

#### 주차장 차단기·빈자리 안내기

차가 입구에 접근하면 초음파가 감지하고, 자리가 남아 있을 때만 서보 차단기를 연다. 출차는 버튼으로 모의하고 FND에 빈자리 수를 표시하며, 만차에서는 진입을 거부한다.

#### 키패드 잠금장치

등록한 비밀번호가 맞으면 서보가 잠금 해제 위치로 이동한다. 틀린 입력 횟수, 연속 실패 시 대기시간, 자동 잠금 상태를 표시해 사용자 조작 흐름을 완결할 수 있다.

#### 각도 지정 회전 스테이지

키패드에 한 바퀴를 몇 등분할지 입력하면 스텝모터 원판이 정해진 간격마다 멈춘다. MCU는 전체 스텝 수를 구간별로 배분하고 화면에 진행률과 남은 횟수를 표시한다.

#### 자동 블라인드 컨트롤러

CdS에서 밝거나 어두운 상태가 일정 시간 유지되는지 확인한 뒤 스텝모터를 움직인다. 수동·자동 전환과 열림 범위 저장을 제공하고, 경계에서 조도가 흔들릴 때 불필요한 왕복을 줄인다.

#### 소형 온실 관리 콘솔

DHT11과 CdS에서 받은 입력으로 조명 LED, 서보 환기창과 송풍기 구동 명령을 제어한다. 키패드로 작물 프로필을 고르면 목표 온습도와 조명 조건이 바뀐다.

#### 2인 반응시간 측정기

무작위 대기 후 LED가 켜지면 두 참가자가 각각 버튼을 누른다. 타이머와 GPIO 인터럽트로 응답 시각을 재고, 먼저 눌러 실격된 경우와 정상 기록을 구분해 FND에 표시한다.

#### 초음파 피에조 악기

초음파로 손의 거리를 읽고 거리 구간을 음계에 대응시켜 피에조에서 소리를 낸다. 화면에서 현재 음을 확인할 수 있고, 버튼으로 연주 모드와 짧은 기록 재생을 전환한다.

#### 16스텝 피에조 시퀀서

4×4 키패드의 각 칸에 소리를 넣고 가변저항으로 BPM을 정하면, MCU가 순서대로 패턴을 반복 재생한다. OLED에는 재생 위치가 움직이며 사용자가 연주 중에도 패턴을 편집할 수 있다.

#### 전자 방탈출 콘솔

키패드 암호, 가변저항 값 맞추기, 버튼 타이밍처럼 다른 입력을 쓰는 퍼즐을 차례로 푼다. FND에는 남은 시간이 표시되며, 끝까지 풀면 서보가 잠금 해제를 표현한다.

#### 모스 부호 훈련기

버튼을 누른 시간과 입력 사이 간격으로 점과 선을 구분하고 OLED에 해석 결과를 표시한다. 피에조로 정답을 들려주고 입력 정확도와 타이밍 오차를 채점한다.
